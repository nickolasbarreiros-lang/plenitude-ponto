# Checklist de homologação RC6.0

## Registro de ponto
- [ ] Entrada registra somente uma marcação.
- [ ] Início do almoço respeita a ordem.
- [ ] Retorno fica bloqueado pelo intervalo mínimo.
- [ ] Saída final só aparece após retorno.
- [ ] Clique duplo não cria duplicidade.

## Cálculos
- [ ] Entrada dentro da tolerância não gera débito.
- [ ] Entrada fora da tolerância gera débito correto.
- [ ] Saída usa a política configurada.
- [ ] Crédito positivo entra quando o switch está ativado.
- [ ] Débito e crédito mensal conferem com o espelho.

## Administração
- [ ] Card Pendências confere com a tela correspondente.
- [ ] Funcionário inativo não gera alertas.
- [ ] Atraso mostra a tolerância atual da empresa.
- [ ] Troca do funcionário selecionado atualiza todo o painel.

## Contingência
- [ ] Offline abre sem depender do login remoto.
- [ ] Estado do dia é respeitado.
- [ ] Registro local persiste após fechar o navegador.
- [ ] Sincronização não duplica marcações.

## Segurança
- [ ] Funcionário inativo não consegue registrar ponto.
- [ ] Dispositivo não autorizado é bloqueado.
- [ ] Sessão expirada volta ao login.
- [ ] PIN Mestre é exigido nas ações destrutivas.

## Relatórios e fechamento
- [ ] Espelho cabe em A4.
- [ ] Feriados zeram a carga prevista.
- [ ] Competência fechada não recebe novas alterações.
- [ ] Reabertura restaura os fluxos administrativos.
