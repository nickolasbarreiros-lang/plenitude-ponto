# RC5.17 — correção do estado visual online

- Corrige CSS que sobrescrevia o atributo `hidden`.
- Remove à força qualquer resíduo visual de contingência quando o servidor está online.
- Oculta o aviso de sincronização com fila zerada.
- Oculta o selo Gravação local no modo online.
- Remove classes de bloqueio e reabilita o botão quando a próxima etapa é válida.
