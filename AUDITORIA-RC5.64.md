# RC5.64 — painel administrativo de diagnóstico

Criada a página `diagnostico.html`, disponível apenas para administradores.

Exibe:

- horário local do computador;
- horário oficial do Supabase;
- diferença entre os relógios;
- fonte efetivamente usada pelo sistema;
- última sincronização;
- timezone;
- offset em milissegundos;
- estado do Service Worker;
- script e escopo ativos;
- versão de CSS e JavaScript carregada;
- diagnóstico geral com alertas.

Não exige SQL novo.
