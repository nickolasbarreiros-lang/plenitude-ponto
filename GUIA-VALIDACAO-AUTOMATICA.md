# Guia da Validação Automática

1. Execute o SQL `supabase-rc3-validacao-automatica.sql`.
2. Publique os arquivos da RC3.
3. Abra **Homologação**.
4. Clique em **Validar automaticamente**.
5. Itens com dados comprobatórios serão marcados como Aprovado ou Reprovado.
6. Itens de interface e comportamento continuam exigindo teste manual.
7. Corrija qualquer item vermelho, repita o cenário e execute a validação novamente.
