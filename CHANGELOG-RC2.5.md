# Plenitude Ponto 1.0.0 RC2.5

## Checklist de homologação ampliado

- Criada a seção **Robustez operacional**.
- Adicionados testes de múltiplos cliques, F5, duas abas, ordem das etapas,
  quinta marcação e janela mínima entre registros.
- Cada teste agora possui status:
  - Não iniciado
  - Em teste
  - Aprovado
  - Reprovado
- Cada teste possui campo próprio de observação.
- O progresso considera apenas itens aprovados.
- A presença de item reprovado altera o resultado geral para **Reprovado**.
- O relatório exportado inclui status e observações individuais.
