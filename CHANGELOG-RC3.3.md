# Plenitude Ponto 1.0.0 RC3.3

## Fluxo de solicitação de ajuste

- O formulário inicia fechado.
- O botão **Abrir nova solicitação** apenas abre o modo de edição.
- Ao abrir, o botão muda para **Cancelar solicitação**.
- **Enviar solicitação** é o único botão que grava os dados no Supabase.
- Após o envio, o formulário fecha e volta ao estado inicial.
- O botão mostra **Enviando...** durante o processamento.
- Foi incluída uma orientação clara acima do formulário.
